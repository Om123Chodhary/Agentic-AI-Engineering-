## 📖 My 3-Month Agentic AI Engineering Journey

This repository is not a result of a 22-day sprint. While the curriculum is structured over 22 days, mastering these concepts while working with real-world constraints took me **over 3 months of consistent, daily effort (7-10 hours/day)**.

*   **Phase 1: The Foundations (Weeks 1-4):** Rebuilt core architectures from scratch, focusing on state management, tool calling, and manual LLM loops.
*   **Phase 2: Production & Security (Weeks 5-8):** Tackled real-world engineering problems like API rate limits, prompt injection, multi-user session isolation, and Docker networking.
*   **Phase 3: Advanced Frameworks & Deployment (Weeks 9-12):** Integrated LangGraph, CrewAI, and LangChain, and deployed a full-stack, Dockerized application on Render.

Every commit in this repository represents hours of debugging, reading documentation, and breaking/fixing systems to understand the underlying mechanics.
